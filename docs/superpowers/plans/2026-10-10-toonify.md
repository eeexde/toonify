# Toonify Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Toonify, a mobile-first installable PWA manhwa reader backed by MangaDex (primary) and ScraperGo (secondary), with a shared server cache that protects upstreams from rate limiting.

**Architecture:** Next.js 15 App Router app. The browser only calls same-origin `/api/*` route handlers. Route handlers go through `SourceService`, which wraps each `Source` adapter (MangaDex, ScraperGo, Mock) in a stale-while-revalidate cache (Upstash or in-memory LRU) plus per-upstream token-bucket rate limiters. User data (library, history, progress, settings) lives in IndexedDB via Dexie. TanStack Query caches API responses client-side (persisted to IndexedDB); a Serwist service worker caches the app shell and images.

**Tech Stack:** Next.js 15.5, React 19, TypeScript (strict), Tailwind CSS 4, TanStack Query 5, Dexie 4 + dexie-react-hooks, zod 4, @upstash/redis, Serwist 9, sonner, Vitest, Playwright, fake-indexeddb.

**Spec:** `docs/superpowers/specs/2026-10-10-toonify-design.md`

## Global Constraints

- Node 24, npm. Next.js pinned to `15.5.x`; build uses webpack (Serwist requirement), never `--turbopack`.
- `next.config.ts` MUST set `allowedDevOrigins: ['192.168.*.*', '100.*.*.*', '**.ts.net']`.
- The browser never calls `api.mangadex.org`, `*.mangadex.network`, `uploads.mangadex.org` or `scrapergo.vercel.app` directly. All MangaDex images go through `/api/img/*`.
- Every MangaDex request sends `User-Agent: toonify/0.1 (+${APP_URL})` and no `Via` header.
- Title ids are prefixed: `md:<uuid>`, `sg:<slug>`, `mock:<slug>`. Chapter ids are opaque strings.
- Cache key namespace: `v1:<source>:<kind>:<args>`.
- Cache TTLs (seconds, fresh / stale): home 600/604800, search 1800/604800, title 3600/2592000, chapter 2592000/7776000, md at-home 600/0, health 60/0.
- Rate limits: MangaDex general 4 req/s burst 4; MangaDex at-home 0.5 req/s burst 5 (≤30/min); ScraperGo 1 req/s burst 5; max wait for a token 3000 ms.
- API JSON envelope: success `{ data, stale }`, error `{ error }`.
- English translations only. MangaDex content ratings: `safe`, `suggestive`; plus `erotica`, `pornographic` only when the 18+ setting is on.
- 18+ is off by default and enabling it requires a confirmation dialog.
- Dark theme is the default. Mobile bottom tab bar below 768 px, top bar at ≥ 768 px.
- Attribution: "Data provided by MangaDex" in footer/settings; scanlation group shown at chapter end. No ads, no paid features.
- `SOURCE_MODE=mock` enables MockSource only; default `live` enables MangaDex (`md`) + ScraperGo (`sg`).

## Review Focus

1. Search terms with spaces, slashes, `%`, `?`, `#`, or non-Latin characters must be URL-encoded for every upstream and never break the route (tests in Task 7 and Task 9).
2. A title whose chapters are all external-only (licensed) must render, show no "Start reading" button, and prev/next must skip external chapters (tests in Task 6 and Task 16).
3. Chapter numbers that are `null` (oneshots), decimals (`10.5`), or duplicated by several scanlation groups must sort stably and stay distinct (test in Task 6).
4. Importing a garbage, wrong-version or partially valid backup file must be rejected with a message and must not write anything (test in Task 11).
5. An upstream that hangs or answers 429 must not hang the request: fetch times out at 10 s and 429 pauses the bucket using `Retry-After` (test in Task 5).

```ts
import { InvalidIdError } from "./errors";

export const SOURCE_KEYS = ["md", "sg", "mock"] as const;
export type SourceKey = (typeof SOURCE_KEYS)[number];

export function isSourceKey(s: string): s is SourceKey {
  return (SOURCE_KEYS as readonly string[]).includes(s);
}

export function encodeId(source: SourceKey, raw: string): string {
  return `${source}:${raw}`;
}

export function decodeId(id: string): { source: SourceKey; raw: string } {
  let decoded: string;
  try {
    decoded = decodeURIComponent(id);
  } catch {
    throw new InvalidIdError();
  }
  const i = decoded.indexOf(":");
  if (i <= 0) throw new InvalidIdError();
  const source = decoded.slice(0, i);
  const raw = decoded.slice(i + 1);
  if (!isSourceKey(source) || raw.length === 0) throw new InvalidIdError();
  return { source, raw };
}
```

`src/lib/cache/memory.ts`:
```ts
import type { CacheEntry, CacheStore } from "./store";

interface Slot {
  entry: CacheEntry<unknown>;
  expiresAt: number;
}

export class MemoryLRUStore implements CacheStore {
  private map = new Map<string, Slot>();

  constructor(
    private maxEntries = 500,
    private now: () => number = () => Date.now(),
  ) {}

  async get<T>(key: string): Promise<CacheEntry<T> | undefined> {
    const slot = this.map.get(key);
    if (!slot) return undefined;
    if (this.now() > slot.expiresAt) {
      this.map.delete(key);
      return undefined;
    }
    this.map.delete(key);
    this.map.set(key, slot);
    return slot.entry as CacheEntry<T>;
  }

  async set<T>(key: string, entry: CacheEntry<T>, ttlSeconds: number): Promise<void> {
    this.map.delete(key);
    this.map.set(key, { entry, expiresAt: this.now() + ttlSeconds * 1000 });
    while (this.map.size > this.maxEntries) {
      const oldest = this.map.keys().next().value as string;
      this.map.delete(oldest);
    }
  }

  async delete(key: string): Promise<void> {
    this.map.delete(key);
  }
}
```

```ts
import { Redis } from "@upstash/redis";
import type { CacheEntry, CacheStore } from "./store";

export class UpstashStore implements CacheStore {
  private redis: Redis;

  constructor(url: string, token: string) {
    this.redis = new Redis({ url, token });
  }

  async get<T>(key: string): Promise<CacheEntry<T> | undefined> {
    const v = await this.redis.get<CacheEntry<T>>(key);
    return v ?? undefined;
  }

  async set<T>(key: string, entry: CacheEntry<T>, ttlSeconds: number): Promise<void> {
    await this.redis.set(key, entry, { ex: Math.max(1, Math.ceil(ttlSeconds)) });
  }

  async delete(key: string): Promise<void> {
    await this.redis.del(key);
  }
}
```

`src/lib/cache/cached.ts`:
```ts
import type { CacheStore } from "./store";

export interface CachePolicy {
  fresh: number;
  stale: number;
}

export interface CachedResult<T> {
  value: T;
  stale: boolean;
}

export type Defer = (p: Promise<unknown>) => void;

export interface CacheApi {
  cached<T>(key: string, policy: CachePolicy, fn: () => Promise<T>): Promise<CachedResult<T>>;
  invalidate(key: string): Promise<void>;
}

export function createCache(
  store: CacheStore,
  opts: { now?: () => number; defer?: Defer } = {},
): CacheApi {
  const now = opts.now ?? (() => Date.now());
  const defer: Defer = opts.defer ?? ((p) => void p);
  const inflight = new Map<string, Promise<unknown>>();
  const failed = new Set<string>();

  function run<T>(key: string, policy: CachePolicy, fn: () => Promise<T>): Promise<T> {
    const existing = inflight.get(key);
    if (existing) return existing as Promise<T>;
    const p = (async () => {
      try {
        const value = await fn();
        await store.set(key, { value, storedAt: now() }, policy.fresh + policy.stale);
        failed.delete(key);
        return value;
      } catch (err) {
        failed.add(key);
        throw err;
      } finally {
        inflight.delete(key);
      }
    })();
    inflight.set(key, p);
    return p;
  }

  return {
    async cached<T>(key: string, policy: CachePolicy, fn: () => Promise<T>) {
      let entry: Awaited<ReturnType<CacheStore["get"]>> | undefined;
      try {
        entry = await store.get<T>(key);
      } catch (err) {
        console.error("[cache] get failed", key, err);
      }
      if (entry) {
        const ageSeconds = (now() - entry.storedAt) / 1000;
        if (ageSeconds < policy.fresh) return { value: entry.value as T, stale: false };
        const stale = failed.has(key);
        defer(run(key, policy, fn).catch((err) => console.warn("[cache] refresh failed", key, err)));
        return { value: entry.value as T, stale };
      }
      return { value: await run(key, policy, fn), stale: false };
    },
    async invalidate(key: string) {
      await store.delete(key);
    },
  };
}
```

```ts
import { RateLimitedError } from "./source/errors";

export class TokenBucket {
  private tokens: number;
  private last: number;
  private pausedUntil = 0;
  private capacity: number;
  private refillPerSec: number;
  private maxWaitMs: number;
  private now: () => number;
  private sleep: (ms: number) => Promise<void>;

  constructor(o: {
    capacity: number;
    refillPerSec: number;
    maxWaitMs?: number;
    now?: () => number;
    sleep?: (ms: number) => Promise<void>;
  }) {
    this.capacity = o.capacity;
    this.refillPerSec = o.refillPerSec;
    this.maxWaitMs = o.maxWaitMs ?? 3000;
    this.now = o.now ?? (() => Date.now());
    this.sleep = o.sleep ?? ((ms) => new Promise((r) => setTimeout(r, ms)));
    this.tokens = o.capacity;
    this.last = this.now();
  }

  private refill() {
    const t = this.now();
    this.tokens = Math.min(this.capacity, this.tokens + ((t - this.last) / 1000) * this.refillPerSec);
    this.last = t;
  }

  async take(): Promise<void> {
    const deadline = this.now() + this.maxWaitMs;
    for (;;) {
      this.refill();
      const t = this.now();
      if (t >= this.pausedUntil && this.tokens >= 1) {
        this.tokens -= 1;
        return;
      }
      const waitPause = Math.max(0, this.pausedUntil - t);
      const waitToken = this.tokens >= 1 ? 0 : ((1 - this.tokens) / this.refillPerSec) * 1000;
      const wait = Math.ceil(Math.max(waitPause, waitToken));
      if (t + wait > deadline) throw new RateLimitedError();
      await this.sleep(wait);
    }
  }

  pauseFor(ms: number) {
    this.pausedUntil = Math.max(this.pausedUntil, this.now() + ms);
  }
}
```

```ts
import type { TokenBucket } from "../ratelimit";
import { NotFoundError, UpstreamError } from "./errors";

export type FetchJson = (url: string, bucket: TokenBucket) => Promise<unknown>;

export function userAgent(): string {
  return `toonify/0.1 (+${process.env.APP_URL ?? "http://localhost:3000"})`;
}

export function createFetchJson(
  o: { fetch?: typeof fetch; headers?: Record<string, string>; timeoutMs?: number } = {},
): FetchJson {
  const doFetch = o.fetch ?? fetch;
  const timeoutMs = o.timeoutMs ?? 10_000;
  return async (url, bucket) => {
    await bucket.take();
    let res: Response;
    try {
      res = await doFetch(url, {
        headers: { Accept: "application/json", ...o.headers },
        signal: AbortSignal.timeout(timeoutMs),
        cache: "no-store",
      });
    } catch (err) {
      throw new UpstreamError(`Upstream request failed: ${(err as Error).message}`);
    }
    if (res.status === 429) {
      const retryAfter = Number(res.headers.get("Retry-After")) || 5;
      bucket.pauseFor(retryAfter * 1000);
      throw new UpstreamError("Upstream rate limited", 429);
    }
    if (res.status === 404) throw new NotFoundError();
    let body: unknown;
    try {
      body = await res.json();
    } catch {
      throw new UpstreamError(`Upstream returned invalid JSON (${res.status})`, res.status);
    }
    if (!res.ok) {
      const err = new UpstreamError(`Upstream error ${res.status}`, res.status);
      (err as UpstreamError & { body?: unknown }).body = body;
      throw err;
    }
    return body;
  };
}
```

```ts
import type { Chapter } from "./types";

function num(c: Chapter): number {
  const n = c.number === undefined ? NaN : parseFloat(c.number);
  return Number.isFinite(n) ? n : Number.POSITIVE_INFINITY;
}

export function sortChapters(chs: Chapter[]): Chapter[] {
  return chs
    .map((c, i) => ({ c, i }))
    .sort((a, b) => num(a.c) - num(b.c) || a.i - b.i)
    .map(({ c }) => c);
}

export function readableChapters(chs: Chapter[]): Chapter[] {
  return chs.filter((c) => !c.externalUrl);
}

export function neighbors(chs: Chapter[], currentId: string): { prev?: Chapter; next?: Chapter } {
  const list = readableChapters(chs);
  const i = list.findIndex((c) => c.id === currentId);
  if (i === -1) return { prev: undefined, next: undefined };
  return { prev: list[i - 1], next: list[i + 1] };
}
```

```ts
    id: encodeId("md", m.id),
    title: pickTitle(m),
    cover: coverUrl(m),
    badge: MATURE.has(m.attributes.contentRating) ? "18+" : undefined,
  };

export function toChapter(c: MdChapter): Chapter {
  const a = c.attributes;
  const group = c.relationships.find((r) => r.type === "scanlation_group")?.attributes?.name;
  const base = a.chapter ? `Ch. ${a.chapter}` : "Oneshot";
  const name = a.chapter ? (a.title ? `${base}: ${a.title}` : base) : a.title ?? base;
  return {
    id: c.id,
    number: a.chapter ?? undefined,
    name,
    date: a.readableAt ?? a.publishAt,
    group: typeof group === "string" ? group : undefined,
    externalUrl: a.pages === 0 && a.externalUrl ? a.externalUrl : undefined,
  };
}

export function toTitle(m: MdManga, chapters: MdChapter[]): Title {
  const a = m.attributes;
  return {
    id: encodeId("md", m.id),
    title: pickTitle(m),
    altTitles: a.altTitles.flatMap((t) => Object.values(t)),
    cover: coverUrl(m),
    summary: a.description.en ?? Object.values(a.description)[0] ?? "",
    status: a.status ?? undefined,
    authors: relNames(m, "author"),
    artists: relNames(m, "artist"),
    genres: a.tags.map((t) => t.attributes.name.en ?? Object.values(t.attributes.name)[0]).filter(Boolean),
    contentRating: a.contentRating,
    chapters: sortChapters(chapters.map(toChapter)),
  };
```

```ts
const PAGE_SIZE = 24;

function parse<T extends z.ZodType>(schema: T, body: unknown): z.infer<T> {
  const r = schema.safeParse(body);
  if (!r.success) {
    console.error("[mangadex] schema mismatch", r.error.issues.slice(0, 3));
    throw new UpstreamError("MangaDex response did not match schema");
  }
  return r.data;

export class MangaDexSource implements Source {
  private base: string;
  private buckets: { general: TokenBucket; atHome: TokenBucket };

  constructor(private deps: { fetchJson: FetchJson; buckets?: { general: TokenBucket; atHome: TokenBucket }; baseUrl?: string }) {
    this.base = deps.baseUrl ?? "https://api.mangadex.org";
    this.buckets = deps.buckets ?? { general: LIMITERS.mdGeneral, atHome: LIMITERS.mdAtHome };
  }

  private listParams(page: number, opts: ListOpts): URLSearchParams {
    const p = new URLSearchParams();
    p.append("originalLanguage[]", "ko");
    p.append("availableTranslatedLanguage[]", "en");
    p.set("hasAvailableChapters", "true");
    p.append("includes[]", "cover_art");
    p.set("limit", String(PAGE_SIZE));
    p.set("offset", String((page - 1) * PAGE_SIZE));
    for (const r of ["safe", "suggestive", ...(opts.mature ? ["erotica", "pornographic"] : [])]) {
      p.append("contentRating[]", r);
    }
    return p;
  }

  private async list(p: URLSearchParams, page: number): Promise<Page<TitleSummary>> {
    const body = parse(MangaListSchema, await this.deps.fetchJson(`${this.base}/manga?${p}`, this.buckets.general));
    return { items: body.data.map(toSummary), page, hasMore: body.offset + body.limit < body.total };
  }

  home(page: number, opts: ListOpts) {
    const p = this.listParams(page, opts);
    p.set("order[latestUploadedChapter]", "desc");
    return this.list(p, page);
  }

  search(q: string, page: number, opts: ListOpts) {
    const p = this.listParams(page, opts);
    p.set("title", q);
    p.set("order[relevance]", "desc");
    return this.list(p, page);
  }

  async title(rawId: string): Promise<Title> {
    if (!UUID_RE.test(rawId)) throw new InvalidIdError();
    const mp = new URLSearchParams();
    for (const inc of ["author", "artist", "cover_art"]) mp.append("includes[]", inc);
    const manga = parse(MangaEntitySchema, await this.deps.fetchJson(`${this.base}/manga/${rawId}?${mp}`, this.buckets.general));

    const chapters: MdChapter[] = [];
    for (let i = 0, offset = 0; i < MAX_FEED_PAGES; i++) {
      const fp = new URLSearchParams();
      fp.append("translatedLanguage[]", "en");
      fp.set("order[chapter]", "asc");
      fp.append("includes[]", "scanlation_group");
      fp.set("limit", String(FEED_LIMIT));
      fp.set("offset", String(offset));
      for (const r of ["safe", "suggestive", "erotica", "pornographic"]) fp.append("contentRating[]", r);
      const feed = parse(FeedSchema, await this.deps.fetchJson(`${this.base}/manga/${rawId}/feed?${fp}`, this.buckets.general));
      chapters.push(...feed.data);
      offset = feed.offset + feed.limit;
      if (offset >= feed.total || feed.data.length === 0) break;
    }
    return toTitle(manga.data, chapters);
  }

  async atHome(chapterId: string): Promise<AtHome> {
    if (!UUID_RE.test(chapterId)) throw new InvalidIdError();
    const body = parse(AtHomeSchema, await this.deps.fetchJson(`${this.base}/at-home/server/${chapterId}`, this.buckets.atHome));
    return { baseUrl: body.baseUrl, hash: body.chapter.hash, files: body.chapter.data };
  }

  async chapter(rawId: string, chapterId: string): Promise<ChapterPages> {
    const ah = await this.atHome(chapterId);
    return {
      titleId: encodeId("md", rawId),
      chapterId,
      pages: ah.files.map((f) => `/api/img/md/${chapterId}/${f}`),
    };
  }
}
```

```ts
export function chapterNumberOf(chapterId: string, name: string): string | undefined {
  return chapterId.match(NUM_RE)?.[1] ?? name.match(NUM_RE)?.[1];

export function toSummaries(body: z.infer<typeof ListSchema>): TitleSummary[] {
  return body.data.map((d) => ({

function asList(v: string | string[] | undefined): string[] {
  if (!v) return [];
  return (Array.isArray(v) ? v : v.split(",")).map((s) => s.trim()).filter(Boolean);
}

export function toTitle(rawId: string, body: z.infer<typeof DetailSchema>): Title {
  const d = body.data;

    title: d.title,
    altTitles: asList(info["Alt Name"]),
    cover: d.image,
    summary: d.summary ?? "",
    status: d.status,
    authors: asList(info.Author),
    artists: asList(info.Artist),
    genres: asList(info.Genre),
```

```ts
export class ScraperGoSource implements Source {
  private base: string;
  private bucket: TokenBucket;

  constructor(private deps: { fetchJson: FetchJson; bucket?: TokenBucket; baseUrl?: string }) {
    this.base = deps.baseUrl ?? "https://scrapergo.vercel.app";
    this.bucket = deps.bucket ?? LIMITERS.scrapergo;
  }

  private async get<T extends z.ZodType>(path: string, schema: T): Promise<z.infer<T>> {
    let body: unknown;
    try {
      body = await this.deps.fetchJson(`${this.base}${path}`, this.bucket);
    } catch (err) {
      const b = (err as { body?: unknown }).body;
      const fail = FailureSchema.safeParse(b);
      if (fail.success) throw new UpstreamError(`ScraperGo: ${fail.data.message ?? "failed"}`);
      throw err;
    }
    const fail = FailureSchema.safeParse(body);
    if (fail.success) throw new UpstreamError(`ScraperGo: ${fail.data.message ?? "failed"}`);
    const r = schema.safeParse(body);
    if (!r.success) throw new UpstreamError("ScraperGo response did not match schema");
    return r.data;
  }

  async home(page: number, opts: ListOpts): Promise<Page<TitleSummary>> {
    const body = await this.get(`/api/manwha/home/${page}?mature=${opts.mature ? 1 : 0}`, ListSchema);
    const max = Math.max(0, ...(body.pagination ?? []));
    return { items: toSummaries(body), page, hasMore: max > page };
  }

  async search(q: string, page: number, opts: ListOpts): Promise<Page<TitleSummary>> {
    const body = await this.get(`/api/search/${encodeURIComponent(q)}/${page}?mature=${opts.mature ? 1 : 0}`, ListSchema);
    return { items: toSummaries(body), page, hasMore: false };
  }

  async title(rawId: string): Promise<Title> {
    const body = await this.get(`/api/manwha/${encodeURIComponent(rawId)}`, DetailSchema);
    return toTitle(rawId, body);

    return { titleId: encodeId("sg", rawId), chapterId, pages: body.data.images };
```

```ts
import type { CacheApi, CachedResult } from "../cache/cached";
import { POLICIES } from "../cache/policies";
import { InvalidIdError } from "./errors";
import { decodeId, type SourceKey } from "./ids";
import type { AtHome, MangaDexSource } from "./mangadex";
import type { ChapterPages, Page, Source, Title, TitleId, TitleSummary } from "./types";

export class SourceService {
  constructor(private deps: { sources: Partial<Record<SourceKey, Source>>; cache: CacheApi; defaultSource: SourceKey }) {}

  enabledSources(): SourceKey[] {
    return Object.keys(this.deps.sources) as SourceKey[];
  }

  private get(key: SourceKey | undefined): { key: SourceKey; src: Source } {
    const k = key ?? this.deps.defaultSource;
    const src = this.deps.sources[k];
    if (!src) throw new InvalidIdError(`Source "${k}" is not enabled`);
    return { key: k, src };
  }

  async home(page: number, mature: boolean, source?: SourceKey): Promise<CachedResult<Page<TitleSummary>>> {
    const { key, src } = this.get(source);
    return this.deps.cache.cached(`v1:${key}:home:${page}:${mature ? 1 : 0}`, POLICIES.home, () => src.home(page, { mature }));
  }

  async search(q: string, page: number, mature: boolean, source?: SourceKey): Promise<CachedResult<Page<TitleSummary>>> {
    const { key, src } = this.get(source);
    const norm = q.trim().replace(/\s+/g, " ");
    return this.deps.cache.cached(
      `v1:${key}:search:${encodeURIComponent(norm.toLowerCase())}:${page}:${mature ? 1 : 0}`,
      POLICIES.search,
      () => src.search(norm, page, { mature }),
    );
  }

  async title(id: TitleId): Promise<CachedResult<Title>> {
    const { source, raw } = decodeId(id);
    const { src } = this.get(source);
    return this.deps.cache.cached(`v1:${source}:title:${raw}`, POLICIES.title, () => src.title(raw));
  }

  async chapter(titleId: TitleId, chapterId: string): Promise<CachedResult<ChapterPages>> {
    const { source, raw } = decodeId(titleId);
    const { src } = this.get(source);
    return this.deps.cache.cached(`v1:${source}:chapter:${raw}:${chapterId}`, POLICIES.chapter, () => src.chapter(raw, chapterId));
  }

  async mdAtHome(chapterId: string, refresh = false): Promise<AtHome> {
    const md = this.deps.sources.md as MangaDexSource | undefined;
    if (!md) throw new InvalidIdError("MangaDex is not enabled");
    const key = `v1:md:athome:${chapterId}`;
    if (refresh) await this.deps.cache.invalidate(key);
    return (await this.deps.cache.cached(key, POLICIES.atHome, () => md.atHome(chapterId))).value;
  }

  health(): Promise<CachedResult<Record<string, "up" | "down">>> {
    return this.deps.cache.cached("v1:health", POLICIES.health, async () => {
      const out: Record<string, "up" | "down"> = {};
      await Promise.all(
        this.enabledSources().map(async (k) => {
          try {
            await this.deps.sources[k]!.home(1, { mature: false });
            out[k] = "up";
          } catch {
            out[k] = "down";
          }
        }),
      );
      return out;
    });
  }
}
```

```ts
import { NextResponse } from "next/server";
import type { CachedResult, CachePolicy } from "../cache/cached";
import { InvalidIdError, NotFoundError } from "../source/errors";

export function jsonResult<T>(r: CachedResult<T>, policy: CachePolicy): Response {
  const cc = r.stale
    ? "public, s-maxage=60"
    : policy.stale > 0
      ? `public, s-maxage=${policy.fresh}, stale-while-revalidate=${policy.stale}`
      : `public, s-maxage=${policy.fresh}`;
  return NextResponse.json({ data: r.value, stale: r.stale }, { headers: { "Cache-Control": cc } });
}

export function badRequest(message: string): Response {
  return NextResponse.json({ error: message }, { status: 400 });
}

export function errorResponse(err: unknown): Response {
  if (err instanceof NotFoundError) return NextResponse.json({ error: "Not found" }, { status: 404 });
  if (err instanceof InvalidIdError) return badRequest(err.message);
  console.error("[api] upstream failure", err);
  return NextResponse.json({ error: "Source unavailable" }, { status: 502, headers: { "Cache-Control": "no-store" } });
}

export function parsePage(v: string | null): number | null {
  if (v === null) return 1;
  if (!/^\d+$/.test(v)) return null;
  const n = Number(v);
  return n >= 1 && n <= 1000 ? n : null;
}
```

```ts
import { UUID_RE } from "../source/mangadex";

const FILE_RE = /^[A-Za-z0-9_-][A-Za-z0-9._-]{0,199}$/;
const IMG_EXT_RE = /\.(jpe?g|png|webp|gif)$/i;
const SLUG_RE = /^[a-z0-9-]{1,64}$/;

export type ImgTarget =
  | { kind: "md"; chapterId: string; file: string }
  | { kind: "cover"; mangaId: string; file: string }
  | { kind: "mock-cover"; slug: string }
  | { kind: "mock-page"; slug: string; chapter: string; n: number };

function safeFile(f: string | undefined): f is string {
  return !!f && FILE_RE.test(f) && !f.includes("..") && IMG_EXT_RE.test(f);
}

export function parseImgPath(s: string[]): ImgTarget | null {
  const [kind, a, b, c, d] = s;
  if (kind === "md" && s.length === 3 && UUID_RE.test(a ?? "") && safeFile(b)) return { kind: "md", chapterId: a, file: b };
  if (kind === "cover" && s.length === 3 && UUID_RE.test(a ?? "") && safeFile(b)) return { kind: "cover", mangaId: a, file: b };
  if (kind === "mock" && a === "cover" && s.length === 3 && SLUG_RE.test(b ?? "")) return { kind: "mock-cover", slug: b };
  if (kind === "mock" && a === "page" && s.length === 5 && SLUG_RE.test(b ?? "") && /^\d{1,4}$/.test(c ?? "") && /^\d{1,3}$/.test(d ?? "")) {
    return { kind: "mock-page", slug: b, chapter: c, n: Number(d) };
  }
  return null;
}

export function isAllowedImageHost(url: string): boolean {
  try {
    const u = new URL(url);
    return u.protocol === "https:" && (u.hostname === "uploads.mangadex.org" || u.hostname.endsWith(".mangadex.network"));
```

```ts
function pass(res: Response): Response {
  return new Response(res.body, {
    status: 200,
    headers: { "Content-Type": res.headers.get("Content-Type") ?? "image/jpeg", "Cache-Control": IMMUTABLE },
  });

function svg(body: string): Response {
  return new Response(body, { headers: { "Content-Type": "image/svg+xml", "Cache-Control": IMMUTABLE } });

export async function proxyImage(t: ImgTarget, deps: Deps): Promise<Response> {
  const doFetch = deps.fetch ?? fetch;

  if (t.kind === "mock-cover" || t.kind === "mock-page") {
    if (!deps.mockEnabled) return notFound();
    const m = MOCK_TITLES.find((x) => x.slug === t.slug);
    if (!m) return notFound();
    return t.kind === "mock-cover"
      ? svg(mockSvg(m.title, m.hue, 1200))
      : svg(mockSvg(`${m.title} · Ch ${t.chapter} · p${t.n}`, (m.hue + t.n * 25) % 360, 1400));
  }

  if (t.kind === "cover") {
    const res = await tryFetch(`${UPLOADS}/covers/${t.mangaId}/${t.file}`, doFetch);
    return res ? pass(res) : notFound();
  }

  let ah: AtHome;
  try {
    ah = await deps.atHome(t.chapterId, false);
  } catch {
    return new Response("Source unavailable", { status: 502 });
  }
  if (!ah.files.includes(t.file)) return notFound();

  let res = await tryFetch(`${ah.baseUrl}/data/${ah.hash}/${t.file}`, doFetch);
  if (!res) {
    try {
      const fresh = await deps.atHome(t.chapterId, true);
      res = await tryFetch(`${fresh.baseUrl}/data/${fresh.hash}/${t.file}`, doFetch);
    } catch {
      res = null;
    }
  }
  if (!res) res = await tryFetch(`${UPLOADS}/data/${ah.hash}/${t.file}`, doFetch);
  return res ? pass(res) : new Response("Image unavailable", { status: 502 });
}
```

```ts
import type { ToonifyDB } from "./schema";
import { DEFAULT_SETTINGS, type HistoryItem, type ProgressItem, type Settings } from "./types";

export async function toggleLibrary(d: ToonifyDB, item: { titleId: string; title: string; cover: string }): Promise<boolean> {
  return d.transaction("rw", d.library, async () => {
    if (await d.library.get(item.titleId)) {
      await d.library.delete(item.titleId);
      return false;
    }
    await d.library.put({ ...item, addedAt: Date.now() });
    return true;
  });
}

export async function touchLatestChapter(d: ToonifyDB, titleId: string, latestChapterId: string | undefined) {
  if (!latestChapterId) return;
  await d.library.update(titleId, { latestChapterId });
}

export async function recordOpen(d: ToonifyDB, h: Omit<HistoryItem, "readAt">) {
  await d.history.put({ ...h, readAt: Date.now() });
}

export async function saveProgress(d: ToonifyDB, p: Omit<ProgressItem, "updatedAt" | "completed">) {
  await d.transaction("rw", d.progress, async () => {
    const prev = await d.progress.get([p.titleId, p.chapterId]);
    await d.progress.put({ ...p, completed: prev?.completed ?? false, updatedAt: Date.now() });
  });
}

export async function markCompleted(d: ToonifyDB, h: Omit<HistoryItem, "readAt">) {
  await d.transaction("rw", d.progress, d.history, d.library, async () => {
    const prev = await d.progress.get([h.titleId, h.chapterId]);
    await d.progress.put({
      titleId: h.titleId,
      chapterId: h.chapterId,
      pageIndex: prev?.pageIndex ?? 0,
      scrollRatio: 1,
      completed: true,
      updatedAt: Date.now(),
    });
    await d.history.put({ ...h, readAt: Date.now() });
    await d.library.update(h.titleId, { lastChapterSeenId: h.chapterId });
  });
}

export async function setSetting<K extends keyof Settings>(d: ToonifyDB, key: K, value: Settings[K]) {
  await d.settings.put({ key, value });
}

export async function readSettings(d: ToonifyDB): Promise<Settings> {
  const rows = await d.settings.toArray();
  const out: Settings = { ...DEFAULT_SETTINGS };
  for (const r of rows) (out as unknown as Record<string, unknown>)[r.key] = r.value;
  return out;
}
```

```ts
import { z } from "zod";
import type { ToonifyDB } from "./schema";

const Library = z.object({
  titleId: z.string(), title: z.string(), cover: z.string(), addedAt: z.number(),
  lastChapterSeenId: z.string().optional(), latestChapterId: z.string().optional(),
});
const History = z.object({
  titleId: z.string(), title: z.string(), cover: z.string(), chapterId: z.string(), chapterName: z.string(), readAt: z.number(),
});
const Progress = z.object({
  titleId: z.string(), chapterId: z.string(), pageIndex: z.number(), scrollRatio: z.number(), completed: z.boolean(), updatedAt: z.number(),
});
const Setting = z.object({ key: z.enum(["mature", "matureConfirmedAt", "theme", "readerWidth", "source"]), value: z.unknown() });

export const BackupSchema = z.object({
  version: z.literal(1),
  exportedAt: z.number(),
  library: z.array(Library).max(10_000),
  history: z.array(History).max(10_000),
  progress: z.array(Progress).max(200_000),
  settings: z.array(Setting).max(20),
});
export type Backup = z.infer<typeof BackupSchema>;

export class ImportError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "ImportError";
  }
}

export async function exportData(d: ToonifyDB): Promise<Backup> {
  const [library, history, progress, settings] = await Promise.all([
    d.library.toArray(), d.history.toArray(), d.progress.toArray(), d.settings.toArray(),
  ]);
  return {
    version: 1,
    exportedAt: Date.now(),
    library,
    history,
    progress,
    settings: settings.filter((s) => Setting.safeParse(s).success) as Backup["settings"],
  };
}

export async function importData(d: ToonifyDB, input: unknown) {
  const parsed = BackupSchema.safeParse(input);
  if (!parsed.success) throw new ImportError("This file is not a valid Toonify backup.");
  const b = parsed.data;
  await d.transaction("rw", d.library, d.history, d.progress, d.settings, async () => {
    for (const item of b.library) {
      const cur = await d.library.get(item.titleId);
      await d.library.put(cur ? { ...item, ...cur, lastChapterSeenId: cur.lastChapterSeenId ?? item.lastChapterSeenId } : item);
    }
    for (const item of b.history) {
      const cur = await d.history.get(item.titleId);
      if (!cur || cur.readAt < item.readAt) await d.history.put(item);
    }
    for (const item of b.progress) {
      const cur = await d.progress.get([item.titleId, item.chapterId]);
      if (!cur || cur.updatedAt < item.updatedAt) await d.progress.put(item);
    }
    for (const s of b.settings) await d.settings.put(s);
  });
  return { library: b.library.length, history: b.history.length, progress: b.progress.length };
}
```

```ts
import { useSyncExternalStore } from "react";

let stale = false;
const subs = new Set<() => void>();

export const staleStore = {
  get: () => stale,
  set(v: boolean) {
    if (v === stale) return;
    stale = v;
    subs.forEach((cb) => cb());
  },
  subscribe(cb: () => void) {
    subs.add(cb);
    return () => subs.delete(cb);
  },
};

export function useStale(): boolean {
  return useSyncExternalStore(staleStore.subscribe, staleStore.get, () => false);
}
```

```ts
export class ApiError extends Error {
  constructor(message: string, public status: number) {
    super(message);
    this.name = "ApiError";
  }
}

export async function api<T>(path: string): Promise<T> {
  let res: Response;
  try {
    res = await fetch(path);
  } catch {
    throw new ApiError("You appear to be offline.", 0);
  }
  let body: { data?: T; stale?: boolean; error?: string } = {};
  try {
    body = await res.json();
  } catch {
    // fall through with empty body
  }
  if (!res.ok) throw new ApiError(body.error ?? `Request failed (${res.status})`, res.status);
  staleStore.set(Boolean(body.stale));
  return body.data as T;
}
```

```ts
export const THRESHOLDS = { prefetch: 0.7, complete: 0.95 } as const;

export function scrollRatio(scrollY: number, docHeight: number, viewport: number): number {
  const max = docHeight - viewport;
  if (max <= 0) return 1;
  return Math.min(1, Math.max(0, scrollY / max));
}

export function currentPageIndex(tops: number[]): number {
  let idx = 0;
  for (let i = 0; i < tops.length; i++) if (tops[i] <= 1) idx = i;
  return idx;
}
```

```ts
"use client";
import { useEffect, useRef } from "react";
import { db } from "@/lib/db/schema";
import { saveProgress } from "@/lib/db/actions";
import { currentPageIndex, scrollRatio, THRESHOLDS } from "@/lib/reader/progress";

interface Args {
  titleId: string;
  chapterId: string;
  pageCount: number;
  onPrefetch: () => void;
  onComplete: () => void;
  onScrollDown: () => void;
}

function pageTops(): number[] {
  return Array.from(document.querySelectorAll<HTMLElement>("[data-page-index]")).map((el) => el.getBoundingClientRect().top);
}

export function useReaderTracking({ titleId, chapterId, pageCount, onPrefetch, onComplete, onScrollDown }: Args) {
  const cb = useRef({ onPrefetch, onComplete, onScrollDown });
  cb.current = { onPrefetch, onComplete, onScrollDown };

  // Restore saved position once pages are rendered.
  useEffect(() => {
    if (pageCount === 0) return;
    let cancelled = false;
    db.progress.get([titleId, chapterId]).then((p) => {
      if (cancelled || !p || p.completed || p.pageIndex <= 0) {
        if (!p) window.scrollTo(0, 0);
        return;
      }
      document.querySelector(`[data-page-index="${p.pageIndex}"]`)?.scrollIntoView({ block: "start" });
    });
    return () => {
      cancelled = true;
    };
  }, [titleId, chapterId, pageCount]);

  // Track scroll, thresholds and periodic saves.
  useEffect(() => {
    if (pageCount === 0) return;
    let prefetched = false;
    let completed = false;
    let dirty = false;
    let lastY = window.scrollY;

    const ratio = () => scrollRatio(window.scrollY, document.documentElement.scrollHeight, window.innerHeight);
    const save = () => {
      if (!dirty) return;
      dirty = false;
      void saveProgress(db, { titleId, chapterId, pageIndex: currentPageIndex(pageTops()), scrollRatio: ratio() });
    };
    const onScroll = () => {
      dirty = true;
      const y = window.scrollY;
      if (y > lastY + 10) cb.current.onScrollDown();
      lastY = y;
      const r = ratio();
      if (!prefetched && r >= THRESHOLDS.prefetch) {
        prefetched = true;
        cb.current.onPrefetch();
      }
      if (!completed && r >= THRESHOLDS.complete && y > 0) {
        completed = true;
        cb.current.onComplete();
      }
    };
    const onHide = () => {
      if (document.visibilityState === "hidden") save();
    };

    window.addEventListener("scroll", onScroll, { passive: true });
    document.addEventListener("visibilitychange", onHide);
    window.addEventListener("pagehide", save);
    const timer = setInterval(save, 2000);
    return () => {
      save();
      clearInterval(timer);
      window.removeEventListener("scroll", onScroll);
      document.removeEventListener("visibilitychange", onHide);
      window.removeEventListener("pagehide", save);
    };
  }, [titleId, chapterId, pageCount]);
}
```

```tsx
    if (e.clientX > w / 3 && e.clientX < (2 * w) / 3) setOverlay((v) => !v);

        next={next}
```

```tsx
    }
  };

  const clearImages = async () => {
    if ("caches" in window) await caches.delete("toonify-images");
    toast.success("Image cache cleared.");
  };

  const sources = Object.entries(health.data ?? {});

  return (
    <div className="mx-auto max-w-xl">
      <h1 className="mb-2 text-xl font-bold">Settings</h1>

      <Row label="Show 18+ content" hint="Adds mature titles to browse and search.">
        <button role="switch" aria-checked={s.mature} aria-label="Show 18+ content" onClick={toggleMature}
          className={`h-7 w-12 rounded-full p-0.5 transition ${s.mature ? "bg-accent" : "bg-line"}`}>
          <span className={`block h-6 w-6 rounded-full bg-white transition ${s.mature ? "translate-x-5" : ""}`} />
        </button>
      </Row>

      <Row label="Theme">
        <select aria-label="Theme" value={s.theme} onChange={(e) => setSetting(db, "theme", e.target.value as Settings["theme"])}
          className="h-10 rounded-lg border border-line bg-card px-3 text-sm">
          <option value="dark">Dark</option>
          <option value="light">Light</option>
          <option value="system">System</option>
        </select>
      </Row>

      <Row label="Reader width" hint="Desktop only.">
        <select aria-label="Reader width" value={s.readerWidth} onChange={(e) => setSetting(db, "readerWidth", Number(e.target.value))}
          className="h-10 rounded-lg border border-line bg-card px-3 text-sm">
          {[600, 720, 900, 1200].map((w) => <option key={w} value={w}>{w}px</option>)}
        </select>
      </Row>

      {sources.length > 1 && (
        <Row label="Source">
          <select aria-label="Source" value={s.source} onChange={(e) => setSetting(db, "source", e.target.value as Settings["source"])}
            className="h-10 rounded-lg border border-line bg-card px-3 text-sm">
            {sources.map(([k, st]) => (
              <option key={k} value={k} disabled={st === "down" && k !== s.source}>
                {k === "md" ? "MangaDex" : k === "sg" ? "ScraperGo (Toonily)" : k}{st === "down" ? " — offline" : ""}
              </option>
            ))}
          </select>
        </Row>
      )}

      <Row label="Backup" hint="Library, history, progress and settings.">
        <div className="flex gap-2">
          <button onClick={doExport} className="h-10 rounded-full border border-line px-4 text-sm">Export</button>
          <button onClick={() => fileRef.current?.click()} className="h-10 rounded-full border border-line px-4 text-sm">Import</button>
          <input ref={fileRef} type="file" accept="application/json,.json" hidden data-testid="import-input"
            onChange={(e) => { const f = e.target.files?.[0]; if (f) void doImport(f); e.target.value = ""; }} />
        </div>
      </Row>

      <Row label="Image cache" hint="Frees space used by offline images.">
        <button onClick={clearImages} className="h-10 rounded-full border border-line px-4 text-sm">Clear</button>
      </Row>

      <ConfirmDialog
        open={confirm}
        title="Show 18+ content?"
        body="Mature titles will appear in browse and search. Confirm you are 18 or older."
        confirmLabel="I am 18 or older"
        onCancel={() => setConfirm(false)}
        onConfirm={async () => {
          await setSetting(db, "mature", true);
          await setSetting(db, "matureConfirmedAt", Date.now());
          setConfirm(false);
        }}
      />
      <Footer />
    </div>
  );
}
```

```ts
import { defaultCache } from "@serwist/next/worker";
import type { PrecacheEntry, SerwistGlobalConfig } from "serwist";
import { CacheFirst, ExpirationPlugin, Serwist } from "serwist";

declare global {
  interface WorkerGlobalScope extends SerwistGlobalConfig {
    __SW_MANIFEST: (PrecacheEntry | string)[] | undefined;
  }
}
declare const self: ServiceWorkerGlobalScope;

const serwist = new Serwist({
  precacheEntries: self.__SW_MANIFEST,
  skipWaiting: true,
  clientsClaim: true,
  navigationPreload: true,
  runtimeCaching: [
    {
      matcher: ({ url, sameOrigin }) => sameOrigin && url.pathname.startsWith("/api/img/"),
      handler: new CacheFirst({
        cacheName: "toonify-images",
        plugins: [new ExpirationPlugin({ maxEntries: 2000, maxAgeSeconds: 30 * 24 * 60 * 60, purgeOnQuotaError: true })],
      }),
    },
    ...defaultCache,
  ],
  fallbacks: {
    entries: [{ url: "/~offline", matcher: ({ request }) => request.destination === "document" }],
  },
});

serwist.addEventListeners();
```

```markdown
# Toonify

Mobile-first manhwa reader (installable PWA). Data from [MangaDex](https://mangadex.org) with an optional ScraperGo (Toonily) source.

    npm run dev          # live sources, http://localhost:3000 (also reachable on LAN/Tailscale)

| Var | Purpose |

| UPSTASH_REDIS_REST_URL / _TOKEN | Shared server cache (recommended on Vercel). Falls back to in-memory. |

## Caching

All upstream calls go through `/api/*` with a stale-while-revalidate cache, request coalescing, stale-on-error, and per-upstream token buckets. Images are proxied via `/api/img/*` with immutable CDN caching and a service-worker cache.
```
